# TickPulse

App source for TickPulse (Next.js UI + Go API + MySQL).

Setup, architecture, tests, and the local demo account are in the **[repository README](../README.md)** at the repo root — that is the document meant for GitHub and for running the project.

An older Node/Express server remains in `backend/` from the first implementation. Use `backend-go/` unless you are looking at that legacy code.
